# Realyn

Dispute management dashboard for hotels.

## Structure

- `apps/web` - React/TypeScript frontend
- `apps/api` - Backend API (coming soon)

## Development

```bash
# Install dependencies
npm install

# Run frontend dev server
npm run dev:web

# Build frontend
npm run build:web
```

## Tech Stack

- Frontend: React 19, TypeScript, Vite
- Backend: TBD
